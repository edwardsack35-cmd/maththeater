Introduction to Sequence and Series
(Arithmetic Progression – AP)

What is a Sequence?

A sequence is a list of numbers arranged in a particular order, following a specific rule or pattern. Each number in the sequence is called a term.

Sequences can be finite or infinite. For example:

•  2, 4, 6, 8, 10   (finite sequence)
•  1, 3, 5, 7, 9, 11, …   (infinite sequence)

What is a Series?

A series is the sum of the terms of a sequence.
For example, if the sequence is 2, 5, 8, 11, then the corresponding series is 2 + 5 + 8 + 11.

Arithmetic Sequence (Arithmetic Progression – AP)

An Arithmetic Sequence (also called Arithmetic Progression or AP) is a sequence in which each term after the first is obtained by adding a constant number. This constant number is called the Common Difference (d).

Examples of Arithmetic Sequences:

•  2, 5, 8, 11, 14, …   (Common Difference d = 3)
•  10, 7, 4, 1, –2, …   (Common Difference d = –3)
•  5, 5, 5, 5, 5, …   (Common Difference d = 0)

Common Difference

The Common Difference (d) is the constant value that is added to each term to get the next term in an Arithmetic Sequence.

d = Second term – First term

or

d = Any term – Previous term

Examples

Example 1: Find the common difference of the sequence: 5, 9, 13, 17, 21

d = 9 – 5 = 4
Check: 13 – 9 = 4,  17 – 13 = 4,  21 – 17 = 4
Therefore, the common difference is 4.

Example 2: Find the common difference of the sequence: 20, 15, 10, 5, 0

d = 15 – 20 = –5
The common difference is –5 (the sequence is decreasing).

Example 3: Find the common difference of the sequence: 7, 7, 7, 7, 7

d = 7 – 7 = 0
The common difference is 0 (all terms are the same).

]

Remember: The common difference can be positive, negative, or zero.
